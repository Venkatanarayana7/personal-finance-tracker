## ✨ Features

- ➕ Deposit money with reason tracking
- ➖ Withdraw money with balance validation
- 💰 View current balance
- 📊 Detailed transaction history with timestamps
- 🔍 Search transactions by keyword or type
- 📁 Export transactions to a readable report
- 💾 Persistent storage using files (JSON & TXT)
- 📈 Summary statistics for deposits and withdrawals
