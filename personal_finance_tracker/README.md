This project focuses on applying core Python concepts to a real-world use case.

## ✨ Features

- ➕ Deposit money with reason tracking
- ➖ Withdraw money with balance validation
- 💰 View current available balance
- 📊 Detailed transaction history with timestamps
- 🔍 Search transactions by keyword or transaction type
- 📁 Export transactions to a readable text report
- 💾 Persistent storage using files (JSON & TXT)
- 📈 Summary statistics for total deposits and withdrawals
