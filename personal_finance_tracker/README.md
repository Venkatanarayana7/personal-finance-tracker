A professional-grade personal finance management system built with Python.

## ✨ Features

- ➕ **Deposit Money** - Track income with reasons
- ➖ **Withdraw Money** - Track expenses with validation
- 💰 **Show Balance** - View current available balance
- 📊 **Transaction History** - Complete record with timestamps
- 🔍 **Search Transactions** - Find by keyword or type
- 📁 **Export Reports** - Generate readable text reports
- 💾 **Data Persistence** - Never lose your data (JSON + TXT storage)
- ⏰ **Timestamps** - Every transaction dated and timed
- 📈 **Statistics** - Total deposits and withdrawals summary

## 🚀 How to Run

1. Make sure Python 3.x is installed
2. Download `finance_tracker_v3.py`
3. Open terminal/command prompt
4. Navigate to folder: `cd path/to/folder`
5. Run:
```bash
  python personal_finance_tracker.py
```
## 📂 Files Created Within this Project 

- `balance.txt` - Stores your current balance
- `transactions.json` - Stores all transaction records
- `transaction_report.txt` - Export file (when requested)
